## A note on feeling lost

A capstone is supposed to feel uncomfortable at first. Nobody hands you the steps; you get a business problem, a set of tools, and a definition of done. That is what infrastructure work looks like in a real job. The way through is small steps: get the environment healthy, measure what exists, make one change, prove it, write it down, repeat. When you are stuck, the steps in [GETTING-UNSTUCK.md](GETTING-UNSTUCK.md) tell you what to try and when to ask.

## Where the rules live

If this guide and a track README ever disagree, the track README wins. Tell the TA so the guide can be fixed.

For Local VM students, your own repository is the final word on names, paths, and tags you set up in Weeks 3 to 10. [LOCAL-VM.md](LOCAL-VM.md) describes the standard setup from those labs.
